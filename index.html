ABOUT THE BUILD

Pepsi, but make it interactive.

This static front-end demo borrows the visual language of the reference flyers: oversized type, bold colour blocks, editorial product shots, stickers, diagonal shapes and product-first layouts.

Every card, filter, modal, basket interaction and flavour generator works in-browser.

For GitHub Pages: upload index.html, styles.css and app.js to a repository and enable Pages from the repository settings.
